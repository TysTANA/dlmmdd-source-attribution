# Diagnostic results

This directory contains compact tables and figures generated by the
post-challenge representation and robustness analysis notebooks.

Datasets, model checkpoints, probability arrays, and sample-level
outputs are not included in this repository.

## Paper-facing artifacts

- `table1_representation_metrics.csv`
- `table2_postprocessing_accuracy.csv`
- `figure2_shared_pca.pdf`
- `figure2_shared_pca.png`

The t-SNE files are supplementary visualizations. Figure 2 uses
orthogonal Procrustes alignment followed by a single shared PCA basis.
